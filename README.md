## 🔧 시스템 요구 사항

- Windows 10 or later, macOS 10.15 or later, or a compatible Linux distribution.
- At least 4GB of RAM.
- A stable internet connection for full functionality.
- Permissions to install software on your device.

1. Launch the application after installation.
2. Log in or create an account if prompted.
3. Set your trading preferences within the settings menu.
4. Start trading and let the AI assist you.
